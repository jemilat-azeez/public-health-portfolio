# Project 1: ACSC Emergency Admissions and Deprivation, England 2003/04-2022/23

Descriptive analysis of NHS Outcomes Framework data on emergency admissions
for ambulatory care sensitive conditions (ACSCs).

## What it shows
- Admission rates by deprivation decile (2015 classification 2003/04-2018/19;
  2019 classification 2018/19-2020/21)
- Absolute gap between the most and least deprived deciles
- Regional, sex, age and COVID-19 period patterns
- A five-page interactive Power BI dashboard

## Tools
R (tidyverse, readxl, janitor, ggplot2) and Microsoft Power BI

## Limitations
- Area-level (ecological) data; no causal claims
- Descriptive only; no statistical tests
- Deprivation decile data end in 2020/21 and are split across two
  classifications that overlap only in 2018/19
- Absolute gap only; relative inequality was not tracked

## Data sources
NHS Outcomes Framework; English Indices of Deprivation 2015 and 2019 (MHCLG).
Raw data are not included.
